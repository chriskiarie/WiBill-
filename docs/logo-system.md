# WiBill Logo System — Usage & Placement

Two marks exist. Each has one job — mixing them up makes the brand feel inconsistent instead of considered.

---

## The two marks

### 1. WB Monogram (circular, compass-line badge)
**Primary mark.** Used everywhere the brand needs to be *identified* — nav, favicon, app icons, anywhere space is tight.

- Survives being shrunk to 16px
- Simple, bold silhouette

**Use for:** nav bar, favicon, apple touch icon, app icons, anywhere below ~64px

### 2. WiBill Wordmark Badge (oval, script lettering, sparkle accents)
**Secondary, decorative mark.** Not built for small sizes — fine script linework blurs below ~80-100px. Its job is *presence*, not identification.

**Use for:** hero sections, large decorative placement. Never in the nav, never as favicon, never under ~80px.

---

## Sizing rules

| Context | Mark | Size |
|---|---|---|
| Nav bar | WB Monogram | 40–48px height |
| Favicon | WB Monogram | 16 / 32 / 48px |
| App icons | WB Monogram | 180 / 192 / 512px |
| Hero / large decorative | Wordmark Badge | 160–220px width, centered |
| Anything smaller than 80px | WB Monogram | **Don't** use wordmark — swap to monogram |

## Clear space

Both marks need ~25% of the mark's height as minimum padding on all sides before any other element starts.

## Background rule

Both marks are black ink with cream interior fill. On the site's black background, the cream interior reads as a small light card floating on black. This is intentional restraint — distinct from the gold accent system used elsewhere.
